# Хата Майстра — React-версія

Сучасна версія сайту на **React + Vite**, перероблена з оригінального
статичного HTML/CSS/JS. Візуальний стиль оновлено (індустріальна
"майстерня": фірмовий помаранчевий колір, графітово-чорний, сітка
креслення в hero-секції, картки з м'якими тінями та анімацією),
але вся бізнес-логіка та інтеграції залишені **без змін**:

- 🚚 **Нова Пошта API** — автопідказки міста/відділення в оформленні
  замовлення (`src/services/novaPoshta.js`) — той самий ключ API.
- 📩 **Telegram-бот** — сповіщення про нове замовлення
  (`src/services/telegram.js`) — той самий токен бота та chat_id.
- 🛒 Кошик, ❤ улюблені, 👤 реєстрація/вхід/кабінет — усе зберігається
  в `localStorage` під тими самими ключами, що й раніше
  (`khata_cart`, `khata_favorites`, `khata_users`, `khata_current_user`,
  `khata_orders`), тож логіка повністю сумісна з попередньою версією.

## Як запустити

Потрібен встановлений [Node.js](https://nodejs.org/) (версія 18+).

```bash
# 1. Встановити залежності
npm install

# 2. Запустити режим розробки (з гарячим перезавантаженням)
npm run dev
```

Після цього відкрийте адресу, яку виведе термінал (зазвичай
`http://localhost:5173`).

Щоб зібрати продакшн-версію (статичні файли для хостингу):

```bash
npm run build
```

Готові файли з'являться в папці `dist/` — їх можна завантажити на
будь-який хостинг (Netlify, Vercel, звичайний хостинг з Apache/Nginx
тощо).

## Структура проєкту

```
src/
  components/     — переіспользувані UI-компоненти (шапка, футер, картка товару...)
  pages/          — сторінки (Головна, Каталог, Товар, Кошик, Кабінет...)
  context/        — глобальний стан: кошик/улюблені/авторизація (StoreContext),
                     спливаючі повідомлення (ToastContext)
  data/           — товари, категорії, бренди, виробники
  services/       — інтеграції з зовнішніми API (Нова Пошта, Telegram)
  index.css       — вся стилістика сайту (дизайн-система)
```

## Про зображення

У завантажених вами файлах не було картинок товарів/брендів (папка
`img/`), тому в цій версії замість `<img>` використано акуратні
іконки (бібліотека `react-icons`, вже була у вашому `package.json`).

Щоб додати справжні фото:
1. Покладіть файли в `public/img/`.
2. У `src/components/ProductIcon.jsx` замініть іконку на
   `<img src={`/img/${product.image}`} alt={product.title} />`.
3. Додайте поле `image` в кожен товар у `src/data/products.js`.

## Що модернізовано

- Перехід із набору `<script>`-функцій, що напряму керують DOM
  (`innerHTML`), на компонентну архітектуру React із маршрутизацією
  (`react-router-dom`) — кожна "сторінка" тепер окремий URL
  (`/catalog`, `/product/1`, `/cart`, `/cabinet` тощо), працює
  кнопка "Назад" у браузері, сторінками можна ділитися посиланням.
- Оновлений візуальний стиль: сітка-креслення у hero, "рулетка" з
  поділками як декоративний елемент, картки товарів з плавною
  анімацією при наведенні, липка (sticky) шапка сайту.
- Адаптивна версія для мобільних: бургер-меню, плаваючі кнопки
  Viber/Telegram.
- Код розбитий на дрібні, легкі для підтримки файли замість одного
  файлу `script.js` на 1600+ рядків.
